Week 1:

Letters Never Sent (encryption): POCTF{2.69.RZN3TNA2MH27HFQ2.QMZZAH6UTNRFZNOZJ4BOXEOBWM}

For this challenge, I was given a short backstory, a letter, and ciphertext that looks like
"XGQSD{2.69.WNH3ZYI2BF27NNV2.SBNVSE6OUZDNMVZNL4RXLJYTWZ}." First, I looked up all the names
in the letter, and the first one, Sir Francis Beaufort, created the Beaufort Cipher, a variation
of the Vigenere Cipher. I knew this would be the cipher used because in the letter it says,
"as one who has long admired the elegance of your method." Since all flags start with POCTF, I
tried to find a key that matched using a formula of key-plaintext=ciphertext, which I made from
studying how the cipher actually works. For example, key-p=x = key-15=23, would be for the first
letter, which comes out to 12, which corresponds to the letter M. I did this for every letter in
POCTF where I got the start of the key, MUSLI. I correlated this to the stars on the edge of the
original letter, which were Marigold, Urn, Swan, Lily, Iris, and Nautilus, and that matches 
everything but the last letter, so I thought the key must be MUSLIN. I plugged that into a decoder
with the ciphertext, and that then gave me the flag.

Everything Left Open (forensics): POCTF{109.69.VUN3TSJ7Q2KO5H6R.OZICSZCRVVHCOKQE2TE72SPZFZ}

The backstory of this challenge explains that the provided file is browser data that was mid-form.
The zip file contained 5 files: a recovery JSONLZ4 file, 2 SQLite files, a JSON file, and a JavaScript 
file. The first thing I thought of doing was recovering the JSONLZ file through Firefox, but that 
produced no bookmarks. I then wanted to uncompress the file, so I went to 
https://www.jeffersonscher.com/ffu/scrounger.html, where I input the file, and I got lucky; the key 
was in the uncompressed file.

The Shape of a Query (web) : POCTF{81.69.KNPEG2D5KJDWCKA5.TLHEHK27ORDACI7KPZH6FGL6E3}

For this challenge, all that is given is a link to a graphql website. First, I wanted to look up all 
the users in my "team" in the database, and I see that there are only 2: researcher_69 and admin_69. 
Obviously, the flag will be hidden under the admin account somewhere, but while typing I get a prompt 
to autofill with privateNotes, so I add that to my original command to get the usernames and it gave me 
the flag. The command is below:
query {
  me {
    team{
      members{
        username
	privateNotes
      }
    }
  }
}

A Borrowed Name (OSINT): POCTF{92.69.bd20a0617d6bcdd9.RETXUFF7ANKXWBHN2C5FY6GQTV}

For this challenge, we are given a simple task: find where a man named Frank Abignale Jr. was in January 
2026. First, I looked up his name to see who he was, and I found a website about him. The website also 
lists what he has done since 2002. I read through the descriptions, and there was only one in January 
2026: he was giving a cybersecurity presentation in Nassau, Bahamas. I entered Nassau in the box, and 
it spat out the flag.
